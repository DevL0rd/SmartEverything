# Unicode Emoji 16.0 catalogue

The bundled English names, category order and glyph sequences come from [Unicode Emoji 16.0 test data](https://www.unicode.org/Public/emoji/16.0/emoji-test.txt), published by Unicode, Inc. The source SHA-256 is `24f0c534e86cf142e2496953e8f0e46a3e702392911eddcd29c6cced85139697`.

The compact JSON groups `[glyph, name]` tuples by the source category. It keeps every fully qualified sequence and standalone component in source order. Minimally qualified and unqualified spellings are omitted. The hexadecimal sequence in each source row matches the glyph after the comment marker. The adjacent Unicode license applies to this data.
